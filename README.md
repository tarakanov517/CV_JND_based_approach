# Saliency prediction

[MIT/Tuebingen Saliency Benchmark](https://saliency.tuebingen.ai/) - бенчмарк для оценки качества моделей предсказания айтрекинга

Включает тестирование на нескольких датасетах, один из них это [Leaderboard COCO Freeview](https://saliency.tuebingen.ai/results_COCO-Freeview.html). C него и взял 3 лучших модели для тестирования

## Про COCO Freeview:

Какие картинки:

- 6202 изображения из набора COCO trainval, те же, что в COCO-Search18. Размер приведён к 1680×1050 с сохранением пропорций и дополнением полями
- Половина (3101) содержит один из 18 целевых предметов, другая половина (3101) его не содержит
- 18 категорий предметов: бутылка, миска, машина, стул, часы, чашка, вилка, клавиатура, нож, ноутбук, микроволновка, мышь (компьютерная), духовка, комнатное растение, раковина, знак «стоп», унитаз и телевизор. То есть в основном интерьеры (кухни, ванные, гостиные, рабочие столы) и немного улиц.

По каким правилам их отбирали:

- Исключали картинки с людьми и животными. Авторы объясняют это тем, что люди сильно притягивают взгляд и исказили бы измерения.
- Убирали изображения, где предмет сильно заслонён или плохо различим.
