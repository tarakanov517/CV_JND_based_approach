# Добавления Гауссовского шума

Было проведено сравнение базовой модели и модели с гауссовским шумом активаций при параметрах σ₁ = σ₂ = σ₃ = 0.3. Базовая модель достигла точности 83% на тестовой выборке, тогда как модель с шумом показала 82%. Таким образом, при выбранном уровне шума общее качество классификации немного ухудшилось.

При этом влияние шума оказалось неодинаковым для разных классов. Для классов cat, dog, horse и truck точность увеличилась (например, для класса dog с 67.4% до 73.9%), тогда как для классов airplane, automobile, bird, frog и ship наблюдалось снижение качества. Это говорит о том, что добавление шума по-разному влияет на извлечение признаков для различных категорий изображений.
