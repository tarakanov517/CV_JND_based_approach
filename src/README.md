# Gaussian noise experiments

## Постановка

Эксперименты проводятся на CIFAR-10. Исходная модель обучается без шума, после чего на ней формируются FGSM- и PGD-выборки. Все шумовые модели проверяются на одних и тех же атакованных изображениях, поэтому метрики характеризуют устойчивость к переносимым атакам на исходную модель.

Используются два типа шума:

- `sigma1`, `sigma2`, `sigma3` — гауссовский шум активаций после первого блока, второго блока и первого полносвязного слоя;
- `omega1`, `omega2`, `omega3` — временный гауссовский шум параметров первого блока, второго блока и классификатора.

Параметрическое возмущение добавляется перед `forward`, участвует в вычислении градиента, затем удаляется перед `optimizer.step()`. Поэтому оптимизатор обновляет чистые параметры, используя градиент, вычисленный в зашумлённой точке.

## Исходная сетка

В `results.csv` находятся 67 уникальных результатов:

- 1 baseline;
- 33 эксперимента с шумом активаций;
- 33 эксперимента с шумом параметров;
- пропусков и повторяющихся моделей нет.

Каждый эксперимент исходной сетки использует только один ненулевой коэффициент шума.

## Результаты baseline

| Clean accuracy | Transfer FGSM | Transfer PGD |
|---:|---:|---:|
| 81,79% | 7,54% | 0,84% |

## Лучшие конфигурации каждой группы

Отбор выполнен в первую очередь по PGD, поскольку это более сильная итеративная атака.

| Тип | Участок сети | Значение | Clean | FGSM | PGD |
|---|---|---:|---:|---:|---:|
| Activation | Block 1 | `sigma1=0.15` | 81,93% | 9,94% | 3,35% |
| Activation | Block 2 | `sigma2=0.15` | 82,61% | 11,79% | 3,75% |
| Activation | Classifier | `sigma3=0.04` | 82,24% | 11,62% | 3,21% |
| Parameter | Block 1 | `omega1=0.002` | 82,79% | 12,40% | 3,48% |
| Parameter | Block 2 | `omega2=0.001` | 82,75% | **13,00%** | 3,61% |
| Parameter | Classifier | `omega3=0.003` | 82,43% | 11,75% | **4,09%** |

Лучший FGSM-результат получен при параметрическом шуме второго блока `omega2=0.001`. Лучший PGD-результат получен при параметрическом шуме классификатора `omega3=0.003`.

## Выводы по исходной сетке

1. Все лучшие шумовые модели сохранили clean accuracy на уровне baseline или немного выше.
2. Наиболее результативным оказался шум параметров. Лучшие значения для всех трёх участков сети дали 3,48-4,09% на PGD.
3. Шум активаций второго блока `sigma2=0.15` оказался лучшим активационным вариантом сразу по FGSM и PGD.
4. Максимальная FGSM accuracy выросла с 7,54% до 13,00%. Это выше случайного уровня 10% для десяти сбалансированных классов, но всё ещё недостаточно для утверждения о сильной устойчивости.
5. Максимальная PGD accuracy выросла с 0,84% до 4,09%. Относительный прирост заметный, но абсолютная точность остаётся ниже случайного уровня.
6. Зависимость качества от интенсивности шума немонотонна. Поэтому увеличение `sigma` или `omega` само по себе не гарантирует улучшение устойчивости.
7. Результаты получены для одного seed и переносимых атак. Для статистических выводов нужны повторения с несколькими seed, а для оценки общей adversarial robustness — white-box атаки на каждую модель.

## Следующий блок: 24 запуска

Следующий блок сравнивает постоянный шум и постепенное введение шума.

Для каждого набора коэффициентов выполняются два режима:

- `fixed`: целевой шум действует с первой эпохи;
- `linear`: 20 эпох без шума, 40 эпох линейного роста и 20 эпох с полным шумом.

Оба режима обучаются 80 эпох с одинаковыми batch size, seed, optimizer и целевыми коэффициентами. Это позволяет отделить влияние curriculum от влияния дополнительного времени обучения.

### 12 наборов коэффициентов

| № | Конфигурация | sigma1 | sigma2 | sigma3 | omega1 | omega2 | omega3 |
|---:|---|---:|---:|---:|---:|---:|---:|
| 1 | Activation Block 1 | 0,15 | 0 | 0 | 0 | 0 | 0 |
| 2 | Activation Block 2 | 0 | 0,15 | 0 | 0 | 0 | 0 |
| 3 | Activation Classifier | 0 | 0 | 0,04 | 0 | 0 | 0 |
| 4 | Parameter Block 1 | 0 | 0 | 0 | 0,002 | 0 | 0 |
| 5 | Parameter Block 2 | 0 | 0 | 0 | 0 | 0,001 | 0 |
| 6 | Parameter Classifier | 0 | 0 | 0 | 0 | 0 | 0,003 |
| 7 | All Activation | 0,15 | 0,15 | 0,04 | 0 | 0 | 0 |
| 8 | All Parameter | 0 | 0 | 0 | 0,002 | 0,001 | 0,003 |
| 9 | Block 1 Combined | 0,15 | 0 | 0 | 0,002 | 0 | 0 |
| 10 | Block 2 Combined | 0 | 0,15 | 0 | 0 | 0,001 | 0 |
| 11 | Classifier Combined | 0 | 0 | 0,04 | 0 | 0 | 0,003 |
| 12 | Full Combined | 0,15 | 0,15 | 0,04 | 0,002 | 0,001 | 0,003 |

Каждая строка запускается в режимах `fixed` и `linear`, поэтому суммарно выполняется 24 эксперимента.

## Гипотезы следующего блока

1. `linear` сохранит более высокую clean accuracy при тех же целевых коэффициентах.
2. Совместный шум нескольких блоков может дать большую устойчивость, чем изолированный шум.
3. Одновременное включение activation- и parameter-noise внутри одного блока может дать дополнительный эффект либо, наоборот, привести к избыточной регуляризации.
4. `Full Combined` проверяет максимальное совместное воздействие, но может сильнее остальных снизить clean accuracy.

## Запуск

```bash
sbatch run.sh
```

Скрипт поддерживает продолжение: перед запуском каждой конфигурации он проверяет наличие её имени в итоговом CSV и пропускает уже завершённые результаты.
