# Анализ экспериментов с гауссовским шумом

## Постановка эксперимента

В таблице `results.csv` содержатся результаты 67 запусков:

- 1 исходная модель без шума (`baseline`);
- 33 эксперимента с шумом активаций;
- 33 эксперимента с шумом параметров;
- для каждого типа шума проверены ранняя часть сети, поздняя часть сети и классификатор.

Устойчивость оценивается на переносимых атаках: атакующие примеры создаются для исходной модели, после чего те же примеры подаются на модели, обученные с шумом. В таблицах ниже указана доля правильных ответов модели, поэтому большее значение означает лучшую устойчивость.

## Выводы

1. **Гауссовский шум почти не снижает качество на чистых данных.** В большинстве экспериментов clean accuracy остаётся около 82–84%. В отдельных случаях она немного превышает результат baseline, что похоже на слабый регуляризующий эффект.

2. **Лучше всего работает шум активаций в ранних и поздних слоях.** Максимальная точность под FGSM получена при шуме поздних активаций с интенсивностью 0,15 — 9,83%. Лучший результат под PGD получен при шуме ранних активаций с интенсивностью 0,15 — 0,33%.

3. **Результат 9,83% нельзя считать практической устойчивостью.** В CIFAR-10 десять сбалансированных классов, поэтому случайное угадывание даёт около 10% точности. Несмотря на рост относительно baseline с 2,15% до 9,83%, модель под FGSM фактически достигает только случайного уровня.

4. **Против PGD защиты не возникло.** Все результаты находятся в диапазоне от 0% до 0,33%, то есть итеративная атака почти всегда успешно меняет предсказание модели.

5. **Шум параметров слабее шума активаций.** Его лучшие значения FGSM составляют 6,96–7,35%, а средние значения близки к 6%. Выраженной монотонной зависимости устойчивости от интенсивности шума не наблюдается.

6. **Рост FGSM-метрики не переносится на более сильную атаку.** Это показывает, что гауссовский шум меняет реакцию модели на конкретные переносимые возмущения, но не формирует устойчивые признаки, сохраняющиеся при PGD.

## Итог

Обучение с гауссовским шумом сохраняет исходную точность модели и частично повышает точность на переносимой FGSM-атаке, однако максимальный результат остаётся на уровне случайного угадывания. На переносимой PGD-атаке все модели практически полностью теряют работоспособность. Следовательно, в проведённых экспериментах гауссовский шум **не обеспечивает содержательной устойчивости к атакам** и может использоваться только как контрольная база для сравнения с человекоподобными шумами.

При окончательном сравнении методов желательно провести несколько запусков с разными seed и приводить среднее значение вместе со стандартным отклонением: текущая таблица содержит по одному результату для каждой конфигурации и не позволяет оценить статистическую устойчивость различий.
