# Адаптивный последовательный рост шума

Каждый запуск начинается с baseline-чекпоинта соответствующего seed. Интенсивность аксонального шума последовательно увеличивается в блоках CORnet-RT. Проверяются три порядка: V1→V2→V4→IT, обратный порядок и V2→V1→V4→IT.

В каждом блоке проверяются уровни 0.25, 0.40, 0.55, 0.70 и 0.85. На каждой ступени та же модель дообучается четыре эпохи: обучение не начинается заново при каждой интенсивности. Ступень сохраняется, пока clean validation accuracy остается не ниже baseline минус 10 процентных пунктов. Первая ступень, нарушившая ограничение, откатывается, после чего рост продолжается в следующем блоке. Transfer PGD на фиксированной validation-выборке записывается для анализа, но не управляет остановкой. После прохода по всем блокам выполняются 10 финальных эпох с зафиксированным профилем. Максимально один запуск занимает 90 дополнительных эпох, но обычно меньше из-за ранней остановки внутри блоков.

Поиск выполняется на seeds 42, 43 и 44. Всего запускается девять адаптивных обучений. Тестовая выборка не участвует в выборе уровней и используется только для финальной оценки.

Эксперимент использует уже рассчитанные baseline-модели. Перед запуском для каждого seed должны существовать файлы `results/baseline/seed_<seed>/model.pt` и `result.json`; переносить старые скрипты экспериментов в эту ветку не требуется.

Запуск из корня проекта:

```bash
mkdir -p logs
ADAPTIVE_JOB=$(sbatch --parsable experiments/adaptive/run.sh | cut -d';' -f1)
TRANSFER_JOB=$(sbatch --parsable --dependency=afterok:$ADAPTIVE_JOB experiments/adaptive/run_transfer.sh | cut -d';' -f1)
echo "ADAPTIVE_JOB=$ADAPTIVE_JOB TRANSFER_JOB=$TRANSFER_JOB"
```

После завершения:

```bash
python3 experiments/adaptive/summarize.py results/adaptive
python3 experiments/adaptive/plot.py results/adaptive
```

Скрипт агрегации создаст `adaptive_results.csv` и `adaptive_summary.csv`. Скрипт построения графиков создаст `adaptive_comparison.png` с итоговыми профилями и метриками, а также `adaptive_paths.png`, где видны изменение clean/transfer accuracy и отклоненные ступени на протяжении последовательного поиска.
