# Эксперименты

Новый согласованный протокол обучения с диапазоном условного шума до 2.50:
[`comparison/README.md`](comparison/README.md). Он включает новые baseline,
фиксированные специалисты, условную модель, адаптивный поиск с порогом 10 п.п.
и общую оценку PGD при ε=2/255, 4/255 и 8/255. Оценка на кластере идёт.
Доступные результаты относятся к завершённым конфигурациям.

Новый условный эксперимент находится в [`conditional/README.md`](conditional/README.md). В нём один checkpoint обучается на распределении четырёх интенсивностей аксонального шума и затем проверяется при разных профилях без повторного обучения.

Предыдущий последовательный подбор интенсивностей сохранён в [`adaptive/README.md`](adaptive/README.md).
